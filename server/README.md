# سيرفر مزامنة «جاوبني»

يجعل الجولةَ واحدةً على كل الأجهزة: النقاطُ والأدوارُ والأسئلةُ
المُجابة يراها الجميع في حينها.

**وهو اختياريّ.** اترك `online-config.js` فارغاً وتبقى اللعبة كما
كانت: «أونلاين» يشارك الفئات والبذرة، وكلُّ جهازٍ ينفرد بنقاطه.

---

## لماذا سيرفرٌ منفصل؟

GitHub Pages **استضافةٌ ساكنة** — تُقدّم الملفات ولا تشغّل شيئاً. فلا
سبيل إلى وضع السيرفر في المستودع نفسه وتشغيله هناك. يُنشر منفصلاً،
ويبقى الموقعُ على GitHub Pages كما هو.

---

## النشر — خطوتان

### ١. ارفعه على Render (مجاناً)

1. ادخل [render.com](https://render.com) وأنشئ حساباً
2. **New → Web Service**، واربط مستودع اللعبة
3. املأ:

   | الحقل | القيمة |
   |---|---|
   | Root Directory | `server` |
   | Build Command | `npm install` |
   | Start Command | `npm start` |

4. بعد النشر يعطيك عنواناً مثل
   `https://jawabni-server.onrender.com`

### ٢. ضَعِ العنوان في اللعبة

في `online-config.js`، وبَدِّل `https` بـ`wss`:

```js
window.ONLINE_SERVER = "wss://jawabni-server.onrender.com";
```

ثم ارفع التغيير، وبدّل نسخةَ `VERSION` في `sw.js` حتى تصل النسخةُ
الجديدة إلى من فتح اللعبة قبلُ.

> **لماذا `wss` لا `https`؟** الوصلُ هنا WebSocket لا صفحةُ ويب.
> ولأن موقعك يُقدَّم عبر `https` فالمتصفّحات تمنع `ws://` غير
> المشفّر من صفحةٍ مشفّرة — فليكن `wss://`.

> **تنبيهٌ على الباقة المجانية في Render:** السيرفر ينام بعد خمس عشرة
> دقيقة من الخمول، فأولُ وصلٍ بعد النوم يتأخّر نحو نصف دقيقة. وبعدها
> يعمل طبيعياً. ولا تضيع جولةٌ بذلك: العميل يُعيد الوصلَ من نفسه.

---

## التجربة محليّاً

```bash
cd server
npm install
npm start
```

ثم في `online-config.js`:

```js
window.ONLINE_SERVER = "ws://localhost:8787";
```

(`ws` بلا `s` هنا جائزٌ لأن الصفحة على `localhost` غير مشفّرة.)

وللاطمئنان أن السيرفر حيّ: افتح `http://localhost:8787/health`.

## كيف يعمل

**جهازُ المُنشئ هو المرجع.** هو وحده يكتب الحالة، وغيرُه يرفع إليه
طلبَ التغيير فينفّذه ويبثّه. وبهذا لا تتنازع الأجهزة: لو ضغط جهازان
«صح» معاً لم تُحتسب النقطة مرّتين.

**والسيرفر وسيطٌ لا يفهم اللعبة.** يجمع أجهزةَ الغرفة ويمرّر بينها
الرسائل، ويحفظ في الذاكرة آخرَ لقطةٍ لكل غرفة ليجد المنضمُّ المتأخّر
الحالةَ فوراً. ولا يكتب على قرص: إن أُعيد تشغيله أعادت أولُ لقطةٍ من
المرجع بناءَ الغرفة.

**ما يُزامَن:** النقاط، والدور، والأسئلة المُجابة، والفرق المجمَّدة،
واللاعبون. وما عداه ثابتٌ من لحظة الإنشاء فيبنيه كلُّ جهازٍ من
البذرة كما كان.

**حدوده:** ٥٠٠ غرفة، و١٢ جهازاً للغرفة، و٢٥٦ كيلوبايت للرسالة، وتُنسى
الغرفةُ الخالية بعد ستّ ساعات.

---

## بلا سيرفر: نوافذُ الجهاز الواحد

إن بقي العنوان فارغاً فالمزامنة تعمل مع ذلك **بين نوافذ المتصفّح على
الجهاز نفسه** عبر `BroadcastChannel`. يصلح للّعب على شاشةٍ واحدة
بنافذتين، وبه جُرّب منطقُ المزامنة كلُّه.
